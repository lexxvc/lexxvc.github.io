🔑 Configurar API Key

Para analizar cotizaciones con IA necesitas una clave de Anthropic. Se guarda solo en tu navegador (nunca sale de tu computadora).

Obtén tu key en console.anthropic.com → API Keys → Create Key.
La clave se guarda en localStorage de tu navegador y nunca se envía a ningún servidor excepto directamente a Anthropic.

Sin API key puedes usar el modo manual para crear timings ingresando los datos a mano.
